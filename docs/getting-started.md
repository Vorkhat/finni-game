## Портативный запуск на Windows

1. Полностью распакуйте ZIP в обычную папку. Не запускайте игру внутри архива.
2. Дважды нажмите START_GAME_WINDOWS.cmd.
3. Игра откроется в браузере по адресу http://127.0.0.1:18765.
4. Оставьте окно запуска открытым, пока играете. Чтобы остановить игру, закройте его.

Node.js, pnpm, сервер API и интернет для такого запуска не нужны. Используются встроенный Windows PowerShell и браузер. Если браузер не открылся автоматически, введите адрес выше вручную. Если порт занят, закройте прежнее окно запуска Финни. В системе с корпоративным запретом сценариев запуск может потребовать помощи администратора.

Не открывайте index.html двойным щелчком: игра использует маршруты и должна открываться через локальный сервер. На macOS/Linux разработчик может использовать сборку apps/web/dist с любым HTTP-сервером, поддерживающим возврат index.html для маршрутов приложения.

## Режим разработки

Проверено с Node.js 24 и pnpm 11.19.0. После установки Node.js установите pnpm 11.19.0 и выполните из корня репозитория:

```sh
npm install -g pnpm@11.19.0
pnpm install --frozen-lockfile
pnpm lint
pnpm test
pnpm build
pnpm dev
```

Скрипты: `pnpm lint` — `tsc --noEmit` по всем пакетам; `pnpm test` — Vitest по `packages/shared`, `packages/content`, `apps/web` и `node --test`; `pnpm build` — lint, сборка API и Vite-сборка в `apps/web/dist`; `pnpm dev` — dev-сервер Vite; `pnpm e2e` — сборка и Playwright; `pnpm preview` — preview на http://127.0.0.1:4173.

Установка зависимостей требует интернета. Backend и база данных текущей игре не нужны; `docker-compose.yml` поднимает локальный API-стаб на `127.0.0.1:3000` только для разработки.

## Android

Нужны JDK 21, Android SDK (Platform 36) и доступ к сети для загрузки зависимостей Gradle. На Windows доступен проверенный portable toolchain: `pnpm android:toolchain`.

```sh
pnpm android:build
```

Команда пересобирает веб-версию, выполняет `cap sync android` и собирает debug APK в `artifacts/android/Finni-1.0.0-debug.apk`. Для Android Studio: `pnpm android:sync`, затем `pnpm android:open`. Полные детали, подпись release и публикация — в [deployment.md](deployment.md).

## Сохранение прогресса

Прогресс хранится в localStorage конкретного браузера и адреса. Ваше текущее сохранение не является частью папки. На другом компьютере или по новому адресу начнётся новая игра; затем прогресс будет сохраняться там. Не очищайте данные сайта, если хотите сохранить игру. Звук включается в настройках и может требовать первого нажатия в браузере.
