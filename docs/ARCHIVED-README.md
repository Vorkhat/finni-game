# Питомец Финни

## Обновление: игровой день и новая мечта

- День длится минимум 4 реальных часа с его начала, включая время при закрытом приложении. Новый доход выдаётся при ручном начале следующего дня, после завершения предыдущего.
- Для завершения обязательны учебная история дня, кормление, совместная игра и уход. На главном экране откройте «День», чтобы увидеть таймер и список дел; те же условия действуют на экране итогов и в GameService.
- Список дел только открывает нужный раздел магазина. Галочки ставятся автоматически по подтверждённым покупкам еды, игрушек и ухода, которые меняют состояние питомца; отмена и нехватка денег не засчитываются. Старые ручные отметки игнорируются.
- Сытость, настроение и уход снижаются каждые 30 минут реального времени (−4/−3/−2), включая отсутствие и промежутки между днями. Нижняя граница — 20: за сутки без заботы все показатели станут низкими. Сохранённая отметка времени исключает повторное списание; старые шаги снижения учитываются при обновлении сохранений.
- Низкие показатели включают грустный образ на главном экране. Ответы в ситуациях и учебных историях сопровождаются отдельной плашкой с радостным или грустным питомцем; при ошибке доступна кнопка «Попробовать ещё раз». В заданиях с распределением бюджета и корзиной реакция вызывается кнопкой «Проверить ответ». Для кота и собаки используются готовые happy/sad-изображения; у дракона эти варианты отсутствуют, используется прежний idle fallback.
- Одна учебная история назначается ежедневно; шесть сюжетов повторяются по кругу. Награда выдаётся один раз за историю в текущем дне. Ситуации остаются дополнительными.
- При выборе другой мечты стоимость достигнутой цели списывается, лишние монеты возвращаются в кошелёк, новая копилка начинается с нуля. Если прежняя цель не достигнута, её сбережения полностью возвращаются в кошелёк. Изменения записываются атомарно вместе с транзакциями.
- Время определяется часами устройства; сервер для игры по-прежнему не требуется. Старые сохранения читаются без очистки.
- Проверки: `daily-life.integration.test.ts` и `e2e/daily-life.spec.ts`; мобильные снимки — `docs/qa/daily-life`.

Offline-first прототип мобильной игры по финансовой грамотности для детей 7–11 лет. Работает полный цикл пяти последовательных дней: доход → план → покупки/задания/события/накопления → итоги план/факт → развитие Финни → следующий день. Есть изолированный Demo Mode и раздел «Для взрослых». Игровое ядро работает локально; backend, PostgreSQL и аккаунт не нужны.

## Быстрый запуск

### Web development

```bash
pnpm install
pnpm dev
```

### Web tests

```bash
pnpm lint
pnpm test
pnpm build
pnpm exec playwright install chromium
pnpm e2e
```

`pnpm dev` запускает только клиент. `apps/api` — экспериментальный модуль будущей инфраструктуры; он не является источником истины и не нужен для MVP. При необходимости его можно запустить отдельно: `pnpm --filter @finni/api dev`.

E2E запускает production preview автоматически на `127.0.0.1:4173`. `pnpm preview` позволяет открыть эту же сборку вручную. В текущем окружении проверки выполнены с Node 24 и pnpm 11.19. Chromium нужен только для разработки, не пользователям приложения.

### Android prerequisites

Capacitor 8 требует Node 22+. Нативная сборка использует JDK 21, Android SDK Platform 36 и Gradle wrapper. На Windows проверен изолированный bootstrap без системной установки:

```powershell
pnpm android:toolchain
```

Он устанавливает инструменты в игнорируемую папку `.tooling/`. Альтернатива — Android Studio с JDK и Android SDK; тогда задайте `JAVA_HOME` и `ANDROID_HOME`. Подробности: [Android build](docs/android-build.md).

### Android sync

```bash
pnpm android:assets
pnpm android:sync
```

`android:sync` всегда сначала создаёт production web bundle и копирует его в Android assets. В `capacitor.config.ts` нет `server.url`; dev server приложению не нужен.

### Debug APK

```bash
pnpm android:build
```

Результат: `artifacts/android/Finni-1.0.0-debug.apk` (debug key, пригоден для локальной установки).

### Release APK

```bash
pnpm android:release
```

Без переменных `FINNI_RELEASE_*` создаётся `artifacts/android/Finni-1.0.0-release-unsigned.apk`. Финальная публикационная подпись описана в [Android signing](docs/android-signing.md); production keystore в репозиторий не добавляется.

### AAB

Та же команда `pnpm android:release` создаёт `artifacts/android/Finni-1.0.0-release-unsigned.aab`. Для RuStore нужен AAB/APK, подписанный постоянным ключом владельца.

### Physical device installation

```powershell
.\.tooling\android-sdk\platform-tools\adb.exe install -r artifacts\android\Finni-1.0.0-debug.apk
```

В текущем окружении Android-устройство и emulator отсутствовали: установка и device UX имеют статус `PHYSICAL DEVICE QA REQUIRED`. Точный сценарий: [Android device QA](docs/android-device-qa.md).

Установка npm/Android build-зависимостей требует сети. Во время игры загружаются только локальные JS/CSS/WebP; внешние шрифты, картинки, API, аналитика и авторизация не используются. Web-preview требует локальный Vite-сервер, установленный APK — нет.

## Offline-first архитектура

```text
UI (apps/web)
  ↓
GameService (application orchestration)
  ↓
Domain operations (packages/shared)
  ↓
StorageAdapter
  ↓
localStorage / in-memory adapter for tests
```

`packages/content` хранит валидируемые определения покупок, целей, заданий, событий, обратной связи и словаря. Формулы и правила находятся только в `packages/shared`. Любое изменение монет создаёт транзакцию; кошелёк и накопления разделены, как и план и факт бюджета.

## Структура

- `packages/shared` — Zod-схемы, доменные типы, экономика, периоды и развитие питомца.
- `packages/content` — data-driven игровой и учебный контент.
- `apps/web` — SolidJS UI, `GameService` и локальный persistence.
- `apps/api` — optional/future NestJS-модуль, изолированный от обязательного цикла.
- `docs` — архитектура, модель данных, экономика и матрица требований.

## Границы прототипа

Этап 1: два реальных образа (рыжий кот и бирюзовый дракон), имя питомца, три цели, динамический Home и настройки. Обычный профиль хранится в `finni.game-profile`; звук/анимации — в отдельном `finni.preferences`. Если профиль создан, но цель ещё не выбрана, загрузка продолжает выбор цели. Повреждённые данные не удаляются и не заменяются автоматически.

Этап 2: 100 монет за начало дня, Budget Planner с шагом 5, покупки 10 товаров, объяснение нехватки денег, deposit/withdrawal с предварительным просмотром, прогресс трёх целей и все 6 интерактивных учебных заданий. План не равен факту и не переводит монеты автоматически. Симуляции не расходуют настоящие игровые деньги; награда за успешное задание выдаётся один раз. История и фактические суммы выводятся из транзакций.

Этап 3: `/day/result` закрывает день после подтверждения и объясняет План/Факт, состояние и развитие. `/progress` показывает историю сохранённых результатов и темы обучения. Wallet переносится, income начисляется один раз за новый день, копилка и цель сохраняются. Исследователь доступен от трёх дней и 750 накопленных сигналов, Финни-профи — от пяти и 1400; стадии не понижаются. Подключены три события (бонус, скидка, уход), celebration эволюции и достигнутой цели. Schema v2 мигрирует старые профили без очистки localStorage.

Этап 4: Demo Mode хранится отдельно в `finni.demo-profile`, а `finni.profile-mode` только выбирает активный namespace. Reset демо не затрагивает обычную игру, exit восстанавливает её точный снимок. `/adult` использует трёхсекундное удержание и открывает прогресс, образовательные пояснения, privacy/offline информацию, раздельные reset/delete. Настройка звука включает короткий локально синтезированный click без аудиофайлов и сети. Добавлены recovery повреждённого сохранения, глобальный UI fallback и direct-route guards.

Этап 5 добавил Capacitor Android wrapper: `ru.onesolution.finni`, minSdk 26, target/compileSdk 36, portrait, локальный bundle, adaptive icon/splash, Android Back и unsigned release pipeline. Незавершённый учебный выбор после reload начинается заново, но уже полученная награда, покупки, план и переводы восстанавливаются. Не рекомендуется одновременно играть в нескольких вкладках: межвкладочная синхронизация не входит в Android MVP.

Этап 6 расширил контент и дневной цикл. Новые расцветки (кот — Белый/Чёрный, дракончик — Зелёный/Фиолетовый) и новый вид Собачка (Далматинец/Коричневый/Хаски) с интерактивным выбором цвета на экране создания. Добавлена серия из 30 «жизненных ситуаций» (вопрос, три варианта с картинками, объяснение), прогресс которых хранится отдельно в `finni.situations`. Задания распределены по 5 дням (`periods.json → dailyTasks`): экран «Задания дня N» показывает истории дня, ситуации дня и прогресс мечты; ситуации открываются по дням и последовательно. В каждом задании есть подсказка. Результат сопровождается анимацией: при верном ответе — фейерверк и радостный питомец, при неверном — грустный питомец и повтор без штрафа. Первый верный ответ в ситуации добавляет `pet.progress.learning` и может приблизить эволюцию; учебные истории по-прежнему кормят period-score, а награды идут в кошелёк. У дракона в арте только три эмоции, поэтому happy/sad для него откатываются на idle.
