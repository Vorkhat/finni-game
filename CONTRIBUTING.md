## Требования

- Node.js 24 и pnpm 11.19.0 (`corepack enable`).
- Установка зависимостей: `pnpm install --frozen-lockfile`.

## Проверки перед коммитом

```sh
pnpm lint
pnpm test
pnpm build
```

Изменения игрового пути дополнительно проверяются E2E (`pnpm e2e`). Не коммитьте при падающих проверках.

## Коммиты

Conventional Commits, заголовок ≤ 72 символов, один коммит — одна тема. Пример:
`docs: restructure documentation and remove junk`. Стейджите только конкретные пути
(`git add <path>`), а не `git add -A`.

## Пул-реквесты

Опишите цель и выполненные проверки, для UI-изменений приложите скриншот. CI-джоб
«Verify Finni» (`.github/workflows/ci.yml`) должен быть зелёным.

## Секреты

Ключи публикации, пароли и токены в репозиторий не добавляются. Подпись release APK/AAB
задаётся переменными окружения `FINNI_RELEASE_*` (см. [docs/deployment.md](docs/deployment.md)).
