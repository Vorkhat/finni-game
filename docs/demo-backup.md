# Резервный путь демонстрации

## Уже существует старый обычный профиль

1. Открыть Settings и нажать «Демо-режим».
2. Подтвердить запуск: обычный профиль останется в отдельном хранилище.

## Демо уже пройдено

1. Settings → «Начать демо заново».
2. Подтвердить — вернётся одинаковый профиль Финни без денег, цели и истории.

## Открыт не Home

1. Нажать «Дом» в нижней навигации или кнопку «Назад».
2. Если открыт взрослый раздел — «Вернуться к Финни».

## Цель уже достигнута

1. Выбрать следующую мечту в карточке достижения; либо
2. Settings → «Начать демо заново», если нужен исходный маршрут с самокатом.

## Нужна обычная игра после демонстрации

1. Settings → «Выйти из демо».
2. Подтвердить: приложение откроет неизменённый normal profile либо onboarding, если его не было.
