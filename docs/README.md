# Документация Финни

Назначение: индекс документации игры «Финни» — по одному назначению на файл.

## Содержание

| Документ | О чём |
|---|---|
| [getting-started.md](getting-started.md) | Установка зависимостей и локальный запуск: Windows без Node.js, веб-разработка, Android. |
| [architecture.md](architecture.md) | Слои приложения, источник истины, persistence и безопасность состояния. |
| [data-model.md](data-model.md) | `GameProfile`, периоды, транзакции и версии схемы хранения. |
| [economy.md](economy.md) | Потоки монет, план и факт, развитие питомца, инварианты. |
| [content.md](content.md) | Расписание программы, товары, цели, задания и события. |
| [demo.md](demo.md) | Сценарий демонстрации на защите за 2–4 минуты. |
| [deployment.md](deployment.md) | Веб-развёртывание, сборка Android, подпись и публикация в RuStore. |
| [api.md](api.md) | Контракты домена и заготовка `apps/api`. |
| [requirements.md](requirements.md) | Матрица требований, трассировка и Android-acceptance. |
| [assets-inventory.md](assets-inventory.md) | Происхождение production-графики. |

Основные точки входа: [корневой README](../README.md) и [DOCUMENTATION.md](../DOCUMENTATION.md).
