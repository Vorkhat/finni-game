# Финни — комплект для передачи, 25 сентября 2026

## Открыть игру на другом компьютере с Windows

1. Полностью распакуйте ZIP в обычную папку. Не запускайте игру внутри архива.
2. Дважды нажмите ../START_GAME_WINDOWS.cmd.
3. Игра откроется в браузере по адресу http://127.0.0.1:18765.
4. Оставьте окно запуска открытым, пока играете. Чтобы остановить игру, закройте его.

Node.js, pnpm, сервер API и интернет для такого запуска не нужны. Используются встроенный Windows PowerShell и браузер. Если браузер не открылся автоматически, введите адрес выше вручную. Если порт занят, закройте прежнее окно запуска Финни. В системе с корпоративным запретом сценариев запуск может потребовать помощи администратора.

Не открывайте index.html двойным щелчком: игра использует маршруты и должна открываться через локальный сервер. На macOS/Linux разработчик может использовать сборку project/apps/web/dist с любым HTTP-сервером, поддерживающим возврат index.html для маршрутов приложения.

## Что входит

- project/apps/web/dist — готовая актуальная веб-версия со всеми изображениями, шрифтами и четырьмя MP3.
- project/apps/web/src и public — исходный код интерфейса и локальные игровые ресурсы.
- project/packages — правила игры и контент: 20 заданий, 60 ситуаций.
- project/android, capacitor.config.ts, resources — Android-проект, конфигурация, значки и заставки.
- project/scripts — инструменты сборки и локальный запуск.
- project/e2e и тесты в исходниках — автоматические проверки.
- package.json, pnpm-lock.yaml, pnpm-workspace.yaml — зависимости и зафиксированные версии.
- project/apps/api — заготовка API; текущая игра работает без неё.

Файлы node_modules и инструменты Android не переносим: разработчик устанавливает зависимости на своём компьютере. Готовая веб-версия уже собрана и от них не зависит. Ключей публикации Android и учётных данных в архиве нет.

## Важно про сохранение

Прогресс хранится в localStorage конкретного браузера и адреса. Ваше текущее сохранение не является частью папки. На другом компьютере или по новому адресу начнётся новая игра; затем прогресс будет сохраняться там. Не очищайте данные сайта, если хотите сохранить игру. Звук включается в настройках и может требовать первого нажатия в браузере.

## Разработчику: веб

Проверено с Node.js 24 и pnpm 11.19.0. После установки Node.js установите pnpm 11.19.0 и выполните в папке project:

```sh
npm install -g pnpm@11.19.0
pnpm install --frozen-lockfile
pnpm lint
pnpm test
pnpm build
pnpm dev
```

Установка зависимостей требует интернета. Для публикации скопируйте содержимое apps/web/dist в корень сайта. Настройте SPA fallback: /home, /tasks и другие маршруты должны возвращать index.html; существующие /assets/ должны отдаваться как файлы. Развёртывание в подпапке требует отдельной настройки базового пути. Backend и база данных текущей игре не нужны.

## Разработчику: Android

Нужны JDK 21, Android SDK (Platform 36), доступ к сети для загрузки зависимостей Gradle. После установки зависимостей проекта:

```sh
pnpm android:build
```

Команда пересобирает веб-версию, выполняет cap sync android и собирает debug APK. Результат: artifacts/android/Finni-1.0.0-debug.apk. Для Android Studio: pnpm android:sync, затем pnpm android:open. APK устанавливается отдельно от этой папки. Перед публикацией требуется проверка на телефоне и собственный ключ подписи; см. docs/android-signing.md. Последняя версия в этом комплекте проверена как веб-приложение; Android APK этой версии в комплект не входит и на физическом телефоне здесь не проверялся.

## Актуальные правила

10 основных игровых дней по 30 минут; по 2 задания и 6 ситуаций на день. Цели: 200 / 300 / 500 монет. Подросток после 4 завершённых дней, взрослый после 8. Финал после завершения программы. Для завершения дня нужно покормить питомца, выполнить учебные дела и вывести показатели из красной зоны. После программы можно продолжать уход и накопления. Открытые наборы из 6 ситуаций можно повторять за 10 монет; задания повторно приносят монеты после 10 завершённых дней.

В проекте сохранены исторические отчёты в docs и FINAL_QA_REPORT.md. Они описывают прежние этапы; по запуску и текущему комплекту руководствуйтесь этим файлом. Скрипты inspect-assets.py, prepare-assets.py и prepare-new-characters.py — исторические инструменты импорта исходных рисунков с прежних компьютеров; для запуска, веб-сборки и Android-сборки они не нужны. Все обработанные игровые изображения уже включены.
